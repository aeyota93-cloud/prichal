# Причал

Лёгкая панель на русском для своего Linux-сервера с Docker. Один маленький
образ (около 10 МБ, 5-10 МБ памяти), без базы данных и без внешних сервисов.

- **Контейнеры:** состояние, нагрузка на процессор и память с графиком,
  запуск, остановка, принудительная остановка, перезапуск, пауза, журнал.
  Опасные действия переспрашивают и объясняют последствия.
- **Сервер:** процессор, память, подкачка, диск, время работы.
- **Подключения** (если на сервере стоит [Amnezia VPN](https://amnezia.org)):
  клиенты AmneziaWG, WireGuard и OpenVPN по именам, кто на связи, трафик;
  устройства на ссылках прокси Telegram (telemt), подписи к ссылкам.
- **Обновления:**
  - пакеты системы с выбором, что ставить (apt, dnf/yum, apk), с живым журналом
    и отметкой «нужна перезагрузка»;
  - приложения на docker compose: проверка новой версии образа в Docker Hub,
    GHCR, Quay и других реестрах, обновление одной кнопкой с копией данных;
  - перезагрузка сервера.
- **Образы:** сколько места занимают, удаление ненужных, очистка.
- **Telegram:** уведомления о падениях контейнеров, перезагрузке сервера,
  нехватке места и памяти, сводка обновлений раз в неделю.

## Требования

- Linux на полноценной виртуализации (KVM, VMware, Hyper-V, «железо»).
  На контейнерных VPS (OpenVZ, LXC) работает всё, кроме вкладки «Обновления».
- Docker 20.10 или новее и Docker Compose v2.
- Процессор amd64 или arm64.

Обновление пакетов поддерживает apt (Debian, Ubuntu), dnf и yum (Fedora, RHEL,
Rocky, Alma), apk (Alpine). На других системах вкладка покажет, что менеджер
пакетов пока не поддерживается; остальное работает.

## Установка

На сервере, от root:

```bash
git clone <адрес-репозитория> /opt/prichal
cd /opt/prichal
./install.sh
```

Скрипт создаст файл настроек `.env` (спросит токен Telegram-бота, можно
пропустить), соберёт образ и запустит панель на `127.0.0.1:9443`. Первая сборка
скачивает образ Go и занимает пару минут.

### Как зайти

Панель доступна только с самого сервера. Откройте SSH-туннель со своего
компьютера:

```bash
ssh -N -L 9443:127.0.0.1:9443 root@адрес-сервера
```

и зайдите на http://localhost:9443. Готовые ярлыки лежат в `clients/`:

- Windows: `prichal-tunnel.cmd`. Впишите адрес сервера в начало файла и
  запускайте двойным щелчком.
- macOS и Linux: `./prichal-tunnel.sh root@адрес-сервера`.

Через тот же туннель можно открыть и другие программы, которые слушают только
127.0.0.1: добавьте их порты (переменная `EXTRA` в `.cmd` или аргументы `.sh`).

## Настройки

Все настройки в `/opt/prichal/.env`, после правки выполните `docker compose up -d`.

| Переменная | Что это |
|---|---|
| `PRICHAL_PORT` | порт на сервере, по умолчанию 9443 |
| `LABEL` | подпись сервера в шапке, по умолчанию имя хоста |
| `PRICHAL_PASSWORD` | пароль для входа |
| `ALLOWED_HOSTS` | доменные имена для доступа через обратный прокси, через запятую |
| `TG_TOKEN`, `TG_USERNAME` | уведомления: токен бота от @BotFather и ваш @username |

**Telegram.** Создайте бота у @BotFather, впишите токен и свой username, откройте
бота и нажмите Start. Бот запомнит ваш чат и будет писать только вам.

## Безопасность

Причал управляет Docker и умеет ставить пакеты и перезагружать сервер, то есть
по сути имеет права root. Поэтому:

- По умолчанию он слушает только `127.0.0.1`, а вход защищает SSH.
- Если опубликовать порт на другом адресе без `PRICHAL_PASSWORD`, панель
  откажется работать и объяснит почему.
- Если ставите панель за обратный прокси (Caddy, Nginx) с доменом, задайте
  `PRICHAL_PASSWORD` и `ALLOWED_HOSTS` и включите HTTPS.
- Защита от чужих сайтов в том же браузере: проверка `Host` и `Origin`,
  каждое действие требует особый заголовок, строгая политика CSP.
- Секреты (ключи VPN, ссылки прокси, токен бота) в браузер не передаются.

Для команд на самом сервере (пакеты, перезагрузка, копии данных) Причал
запускает короткоживущие вспомогательные контейнеры `prichal-host-*` на образе
`alpine`. Долгие задачи идут как отдельные службы systemd (`prichal-*`) и не
обрываются, даже если посреди установки перезапустится Docker. Журналы задач:
`/var/lib/prichal/tasks/`.

## Копии данных приложений

Перед обновлением приложения Причал может сохранить его тома Docker в
`/var/backups/prichal/<проект>/<дата>/` (хранятся 5 последних). Вернуть:

```bash
cd /var/backups/prichal/<проект>/<дата>
docker compose -p <проект> stop <сервис>
docker run --rm -v <том>:/data -v "$PWD":/backup alpine sh -c 'rm -rf /data/* && tar xzf /backup/<том>.tar.gz -C /data'
docker compose -p <проект> up -d <сервис>
```

Образы с тегом-версией (`postgres:16.4`) Причал не обновит до новой версии:
он проверяет только пересборку того же тега. Чтобы перейти на новую, поменяйте
тег в docker-compose.

## Обновление и удаление

```bash
cd /opt/prichal && git pull && ./install.sh      # обновить
cd /opt/prichal && docker compose down -v        # удалить вместе с настройками
```

## Разработка

Нужен Go 1.26. Панель можно запускать у себя, подключив к Docker сервера через
SSH (это даёт полный доступ к Docker сервера, после работы закройте туннель):

```bash
ssh -N -L 127.0.0.1:23750:/var/run/docker.sock root@адрес-сервера
DOCKER_HOST=tcp://127.0.0.1:23750 LISTEN=127.0.0.1:9444 go run .
```

Проверки: `gofmt -l .`, `go vet ./...`, `go test ./...`. Образ под amd64 и arm64
собирается на GitHub при каждом теге `v*` и публикуется в
`ghcr.io/<владелец>/prichal`.
