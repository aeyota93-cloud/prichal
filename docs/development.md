# Разработка

Нужен Go 1.26.9 или новее. В программе используется стандартная библиотека Go.
Интерфейс — HTML, CSS и JavaScript без сборщика и сторонних библиотек.

## Посмотреть интерфейс без сервера

Если установлен Node.js:

```sh
node scripts/preview.cjs
```

Открыть `http://127.0.0.1:19444`. Данные демонстрационные, запросы изменения
данных отключены. `/mobile` — рамка шириной 390 px, `/login.html` — вход.

## Запуск с настоящим Docker

Туннель ниже даёт полный доступ к Docker сервера. Используйте его только
для своего сервера и закройте после работы.

В одном терминале:

```sh
ssh -N -L 127.0.0.1:23750:/var/run/docker.sock root@АДРЕС-СЕРВЕРА
```

В другом, из папки проекта на Linux или macOS:

```sh
DOCKER_HOST=tcp://127.0.0.1:23750 LISTEN=127.0.0.1:9444 go run .
```

Открыть `http://localhost:9444`. Для разработки можно отдельно задать
`DATA_DIR`, чтобы сохранять пароль и настройки между запусками.

## Проверки

```sh
gofmt -l .
go vet ./...
go test ./...
```

GitHub Actions дополнительно запускает тесты с `-race`, `govulncheck` и
`shellcheck`. Тесты shell-скриптов используют поддельные `git` и `docker`;
на Windows они пропускаются. Сборка Docker проверяется для amd64 и arm64.
При публикации тегов `v*` образ отправляется в `ghcr.io/aeyota93-cloud/prichal`.

## Где что лежит

- `main.go` — запуск; `http.go` — защита запросов; `auth.go` — вход и сессии.
- `api_*.go`, `images.go` — обработчики разделов.
- `scripts/` — команды обслуживания сервера, встроенные в программу.
- `web/app.js` — запуск интерфейса; остальные модули `web/` — разделы панели.

Для правок используйте pull request. Не вставляйте данные через `innerHTML`
и не добавляйте атрибуты `style=`: интерфейс работает со строгой CSP.
